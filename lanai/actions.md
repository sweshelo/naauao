# lanai (電波人間のRPG FREE!) のアクション (ActionData)

対象: Base v0 + Update v17408。master `2135000A` の **ActionData** (5017 行 × 0x2C、行 ID あり。行 ID は行番号と一致しない: 行 62 = `0x800011F2`)。戦闘のアクション (モンスターのワザ・自動の行動・道具・装備の自動のアクション・変身) の表。

確度: **確定** = 読むコードを特定し、データとも合う。**推定** = データの値と文 (ワザの名前) を照らしただけ。**未確認** = 観測値だけ。ここでの「推定」はほとんどがデータの集計 (Panana の CI の ROM ジョブで行ごとの値を数えた) で、code.bin はまだ読んでいない。

## 1. 誰がアクションを指すか

| 指す側 | 欄 | 値 | 確度 |
|---|---|---|---|
| モンスターの能力の行 (MonsterParameterMain / Extra / RegularEvent / SpecialEvent) | +0x38〜+0x68 (戦闘開始・ターン開始/終了・被弾時・ワザ × 6) | **行 ID** | 確定 ([monsters.md §3](monsters.md)) |
| 装備 (EquipInfo) の効果 | 種類 0x40〜0x44 の値 | **行番号** | 確定 ([equipment.md §4](equipment.md)) |
| **道具 (UseItemInfo、140 × 0x8)** | **+0x04** | **行番号** (0 = なし) | 推定 (データ) |
| AntennaGroup / DenpaCustom / NpcParameter / CampaignCodeAddParty など | 複数の u32 | 行 ID | 未確認 (値の 9 割以上が ActionData の行 ID) |

- UseItemInfo +0x04: キズぐすり 707 (系統 14)、アンテナパワー 712 (系統 15)、むてきバリア 718 (系統 9、結果「〈name〉は むてきになった」)、ふっかつのくすり 721 (系統 19)、どくなおし〜もとどおりスプレー 725〜748 (系統 18、結果「〈name〉のやけどが治った」…)、えんまく 749 (系統 31、「しかし　逃げられなかった」)、テレポーター 750 (系統 50)、ランプかいふく 797〜800 (系統 45)、けいけんドリンク 851〜853 (系統 43)。各種ブースト・かぎ・ヒロビーロは 0。
- 道具 (種類 0x1x) だけ。ふくぶくろ (0x02)・0x37 にも UseItemInfo の行があるが、+0x04 はアクションではないと推定 (おしょうがつぶくろは 707 = キズぐすりの行)。
- UseItemInfo +0x00 は 0x342 / 0x343 の 2 値 (道具を使える場所の区別と推定、未確認)。

## 3. 系統 (+0x14 bit4-11) の行数

0:20 1:1476 3:1192 4:16 5:3 6:6 7:5 8:10 9:441 10:578 11:3 12:39 13:76 14:90 15:12 16:6 17:3 18:69 19:15 21:5 22:1 23:3 24:4 25:9 26:6 27:91 28:12 29:352 30:6 31:65 32:2 33〜37:1 ずつ 39:4 40〜42:1 ずつ 43:3 44:37 45:4 46:2 47:9 48:2 49:93 50〜51:1 ずつ

データから読める対応 (推定): 1 / 3 = ダメージ、9 / 10 = 状態を付ける、14 = HP 回復 (キズぐすり)、15 / 17 = AP 回復、18 = 状態を治す、19 = 生き返らせる、21 = つかまえる (確定)、23 = 防御 (「〈name〉は　防御している」)、25 = ゴールドを盗む、27 = 仲間を呼ぶ、28 = 分裂、29 / 30 = 変身 (確定)、31 = 逃げる、45 = ランプの回復、43 = 経験値、47〜49 = 毒・のろいなどのターンごとの処理、50 = テレポーター。

## 4. 行を足す

- Panana は行を表の最後に足し、行 ID を最大 + 1 にする (GS テーブルの行 ID の並びを保つ)。変身のアクションの複製 ([monsters.md](monsters.md)) と同じ方法。ゲームが足した行を読むかは、モンスター・装備・道具から指した状態でまだ確かめていない。
- 写した行の「使ったときの文」は MessageAction の行を写して付け替えると、元と別に書き換えられる。

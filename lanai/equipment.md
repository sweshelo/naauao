# lanai (電波人間のRPG FREE!) の装備の効果

対象: Base v0 + Update v17408。アドレスは Update の code.bin (0x100000 起点)。表の置き場は `*0x004EAE44` (マスターのオブジェクト)、ホルダーは 0x28 間隔 ([items.md §1 表の一覧](items.md#1-表の一覧))。

確度: **確定** = 読むコードを特定し、データとも合う。**推定** = コードかデータの片方だけ、または意味づけが推測。**未確認** = 観測値だけ。

RPG2 の装備の効果は [kahara: アイテムの効果](../kahara/item-effects.md)。RPG3 とは種類の番号・欄の位置が違うので流用しない。

## 0. 要点

- 装備の性能は **EquipInfo** (欄ごとに 6 表、0x3C) の行で、アイテムの ItemDataCore +0x00 の行 ID で引く (`FUN_002695C0`)。
- 効果は **2 つまで** (+0x04 / +0x08 に `{値 s16, 種類 u8, 番号 u8}`)。能力値の加算も種類 0x34 の効果の 1 つで、専用の欄はない。**確定**
- 種類 → **ConditionData の行** は `FUN_00165F60(種類, 番号, 値)` の分岐 (§3)。名前・値の書式・範囲・合算のしかたはその行にある (§2)。**確定**
- 種類 0x40〜0x44 は**自動のアクション**: 値 = ActionData の行番号、番号 = 発動の条件 (モンスターの自動行動と同じ表、[monsters.md §7](monsters.md#7-自動行動の発動条件-0x960x99-の-1-バイト))。**確定**
- 首・手などの欄による効果の違いはない。**確定**

## 1. EquipInfo (0x3C)

ホルダーは `+0xBE0 + 欄 × 0x28`。欄は `FUN_002CE478` が種類 (ItemDataCore +0x32) の上位 4 ビットから決める: 0 = 首 (0x9x)、1 = 手 (0xAx)、2 = 足 (0xBx)、3 = 背中 (0xCx)、4 = ふく (0xDx)、5 = 顔 (0x8x)。6 / 7 (0xEx / 0xFx) は表がなく、なし扱い。**確定**

| 表 | 行数 |
|---|---:|
| equipInfo_neck | 265 |
| equipInfo_hand | 294 |
| equipInfo_foot | 206 |
| equipInfo_back | 347 |
| equipInfo_cloth | 365 |
| equipInfo_face | 256 |

どの行もちょうど 1 つのアイテムから参照される。

| off | 型 | 内容 | 確度 |
|---|---|---|---|
| +0x00 | u32 ビット欄 | bit0-4 = **めがねの顔の模様の番号** (種類 0x82 のときだけ読む。`FUN_002D3418` / `FUN_002DA65C` → `FUN_0026CE7C`。23 個のめがねが 1〜23、ほかは 0) | 確定 |
| | | bit5-16 = 1 / 90 / 180 / 300 / 500 / 850 / 1200 / 1700 / 1900 / 2100 の段階。`FUN_00459510` が読み、`FUN_00178920` で「乱数 (0x1000) < 値」なら、倒れた電波人間の装備 (ランダムな 1 欄) を戦利品にする。**装備を落とす確率 (/4096)**。戦闘 +0x119 == 5 のときだけ | 推定 |
| | | bit17-31 = 全行 208 (0xD0 の詰め物の残り) | 未使用 |
| +0x04 | s16 | 効果 1 の値 | 確定 |
| +0x06 | u8 | 効果 1 の種類 | 確定 |
| +0x07 | u8 | 効果 1 の番号。種類 0x40〜0x44 のときは発動の条件 | 確定 |
| +0x08〜+0x0B | | 効果 2 (並びは同じ) | 確定 |
| +0x0C〜+0x3B | u16 × 24 | **おまかせ装備の評価値** (基準ごと)。`FUN_0045959C(アイテム, 添字 < 0x18)` で読み、`FUN_001ED544` が欄ごとに最大の装備を選ぶ。基準 → 添字は `FUN_001ED738` (基準 0x10 → 添字 0 が既定で同点の比べ合いにも使う、1〜9 → 1〜9、10〜15 → 11〜16、0x1A → 10、0x11〜0x17 → 0x11〜0x17)。値は効果から作ったものらしい (こおり属性の武器は添字 3 が +10000、ゴールド・経験値の効果は添字 19 / 20 が大きい、ほかくは 18) | 読み方は確定、意味は推定 |

- `FUN_002A5A0C` が 2 つの効果を `{種類 u8, 副 u8, 番号 u16, 値 s16}` にする。種類が 0x40〜0x44 なら 副 = +0x07・番号 = 0、それ以外は 番号 = +0x07・副 = 0。**確定**
- 効果を変えても評価値は変わらない。おまかせ装備の順位がずれるだけと推定。

### 合算 (`FUN_0016518C(種類, 番号, 旧, 新)`、確定)

| 番号 | 計算 |
|---|---|
| 0 | 0 |
| 1 | 旧 + 新 |
| 2 | 旧 + (新 − 基準) |
| 3 | 旧 × 新 |
| 4 | 旧 × 新 ÷ 100 |
| 5 | 旧 + 新。ただし最大に届くのは、どちらか 1 つが単独で最大のときだけ (それ以外は最大 − 1 で止まる) |

- 最後に [最小, 最大] に切り詰める。
- 行は `FUN_00301C38(種類, 番号, 0)` で、**値に 0 を渡して**引く。このため種類 9 の合算は行 85 (0..8、上書き)、種類 10 は行 94 (2..4、大きいほう) で決まる。

### 表示 (`FUN_002CB570`)

- 名前 = msg_equip、値 = msg_value のタグに値を差し込む。合算が 2 の行は、差し込む前に「値 − 基準」にする。**確定**
- タグ 0x04 は整数、0x103 / 0x105 は符号付き、0x106 / 0x107 は 100 で割った小数 (「倍」)、0x0C / 0x0E は整数と推定。書式を作る関数は見ていない。**推定**
  - 例: こうげき (行 81、基準 100、`+<107>倍`) の値 140 は「+0.4倍」。

| 0x40 | 戦闘開始時 | 未使用 |
| 0x41 | ターン開始時 | 未使用 |

## 5. ユニットへの反映 (確定)

- **`FUN_0045CFE8(ユニット, リスト)`** が欄 0〜7 の装備 (`FUN_002ED844(ユニット, 欄)`) の効果 2 つずつを、`FUN_00269210` で能力リスト (最大 20 件、+0x78 = 件数) に積む。
  - 種類・副・番号が同じ項目があれば `FUN_0016518C` で合算し、なければ追加する。**追加のときは切り詰めない** (1 つだけなら最大を超えた値もそのまま残る)。
  - 種類 0x40〜0x44 だけは、番号を「欄 × 2 + 効果の番号」に書き換えてから積む。このため装備どうしで合算されず、全部が別々に動く。
- そのあと同じ関数が、装備以外の 0x45 / 0x3B / 0x46 と、アンテナの属性の追加 0x4D〜0x54 を積む。装備に 0x43 の 675〜682 (属性の状態異常の追加) があると、アンテナの 0x4D〜0x54 は積まれない。
- `FUN_002B5058` がリストを読み、0x22 / 0x23 / 0x34 を能力値・耐性に加算する。ほかの種類は戦闘の処理が `FUN_00256548(リスト, 種類, 番号)` で引く。
- モンスターの能力 (パッシブ) も同じ種類の空間 ([monsters.md §5](monsters.md#5-能力-パッシブ-の一覧))。

## 6. 実データ

- 効果 1 が空の行: 首 5・ふく 1・顔 1。効果 2 が空の行: 首 77・手 21・足 14・背中 57・ふく 12・顔 31。
- 多い種類: 0x34 能力値 635、0x23 属性たいせい 358、0x22 状態たいせい 352、0x43 139、0x03 106、0x42 105、0x09 96、0x45 94。
- 例: ちからのうでわ = 0x34/2 こうげきりょく +4、ハートのブローチ = 0x42 → 658 (HP自動回復 4%)、しんぴのスカーフ = 0x22/100 全状態異常たいせい +1、プレミアムワンド = 0x07 とくぎ数 +1 / 0x48 ほかく 500 (+4倍)、アンテナダウンバッジ = 0x33 −1。

## 7. 未解決

- u16 × 24 の評価値を効果からどう作るか。
- +0x00 bit5-16 の確率が使われるバトルの種類 (戦闘 +0x119 == 5) の正体。
- 名前が出るが装備で使われていない種類 (0x4B、0x4D〜0x76) を装備に付けたとき、戦闘で効くか。
- msg_value のタグ (0x04 / 0x0C / 0x0E / 0x103 / 0x105 / 0x106 / 0x107) の書式を作る関数。
- ConditionData の +0x0C〜+0x14・+0x22・+0x27、行 126 / 138 の使い道。

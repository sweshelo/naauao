## 確度の目安
- 「確定」: 表の値やコードの動きを、ゲーム内の文言・公式とされる情報・往復の変換で照らし合わせた。例:
  - スタミナの値: ゲーム内のクイズの正解と一致
  - コードの形式: 公式とされるコードをデコードし、同じ値から同じコードを作り直せた
- 「推定」: コードの読み取りだけで、ゲームでの動作は確かめていない。
- エミュレータ・実機での確認はしていない。

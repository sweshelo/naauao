# GS アーカイブ・GS テーブル・GMSG の共通形式

対象は kahara（RPG2 1.1.0）と oahu（RPG3 Base v0 + Update v4096）。出典は再編前の両作 `analysis.md` と [同梱解析ツール](../roms/README.md)。整数は以下では little-endian。ここで共通化するのは入れ物の構造であり、行・ID・タグ・モデル形式は作品ごとに読む。

## GS アーカイブ

| オフセット | 型 | 内容 |
|---|---|---|
| 0x00 | u32 | version: kahara = 5、oahu = 7 |
| 0x04 | u32 | アーカイブハッシュ（ルートのファイル名） |
| 0x08 | u32 | エントリ数 n |
| 0x0C | 28 B × n | エントリ配列 |

エントリ内のオフセット:

| オフセット | 型 | 内容 |
|---|---|---|
| 0x00 | u32 | エントリハッシュ |
| 0x04 | u32 | type |
| 0x08 | u32 | 格納サイズ |
| 0x0C | u32 | アーカイブ先頭からのデータ位置 |
| 0x10 | u32 | comp: 0 = 無圧縮、1 = 1ファイル入り ZIP、6 = Nintendo LZ10 |
| 0x14 | u32 | kahara = 0xFFFFFFFF（−1）、oahu = 1。意味は未確定 |
| 0x18 | u32 | 展開後サイズ |

ZIPには元の名前が入る。同じ名前のエントリハッシュが両作品で一致する例があるが、ルートのアーカイブ名は異なる（master: kahara `56562135`、oahu `21350000`）。type 2 のモデルも kahara は CGFX、oahu は BCH。作品別の対応は [kahara/romfs.md](../kahara/romfs.md) と [oahu/analysis.md](../oahu/analysis.md) を参照。

## GS テーブル

| オフセット | 内容 |
|---|---|
| 0x00 | 行数 |
| 0x04 | 行サイズ |
| 0x0C | テーブル名長 + 2 |
| 0x10 | データ開始オフセット（0x40 / 0x50 など） |
| 0x14 | データサイズ（行数 × 行サイズ） |
| 0x18 | ファイルサイズ |
| 0x30 | テーブル名（ASCII） |

固定値でデータ開始を決めず、ヘッダーを読む。oahu の mapData / treasureGroup / monsterGroup などは +0x20 が非ゼロで、行の後ろに追加領域を持つ。追加領域の意味を共通形式から推定しない。

| テーブル | kahara | oahu |
|---|---|---|
| itemData | 713 × 0x30 | 1191 × 0x40 |
| actionData | 672 × 0x3C | 1126 × 0x30 |
| monsterParameter | 185 × 0x54 | 201 × 0x70 |
| EventObject | 行サイズ 0x50 | 行サイズ 0x58 |

## GMSG メッセージ

| オフセット | 内容 |
|---|---|
| 0x00 | `GMSG` |
| 0x04 | ファイルサイズ |
| 0x08 / 0x0C | 先頭 ID / 末尾 ID（両端を含む）。空の表は last = 0xFFFFFFFF |
| 0x10 | 0 = 本文、1 = `*_IN`（読み） |
| 0x14 | ID 間隔（既存記録では 1） |
| 0x18 / 0x1C | オフセット表位置 / 文字列ベース |

記録された配置はオフセット表が 0x20、文字列ベースが `0x20 + 4 × 件数`。文字列位置は「ベース + ID に対応する u32 オフセット」。本文は先頭の種別コードと本文・終端を持つ。IDはファイルをまたぐ番号で、kahara は連続した範囲、oahu は大きな空きを持つ範囲を使う。

文字列を扱うときは本文の制御コードを解釈する。差し込みタグの引数にもゼロが現れるため、単純なゼロ検索は完全なパーサーにならない。同梱 `gsmb.py` は簡易表示用で、`*_IN` や制御コード全体の仕様を実装した編集器ではない。

| 内容 | kahara | oahu |
|---|---|---|
| ルビ | 0x27 / 0x28 / 0x29 | 0x2B / 0x2C / 0x2D |
| 別メッセージ差し込み | `0x0002 0x0026 ID 0x0000` | `0x0002 0x002A ID 0x0000` |

kahara のパディング、検索関数、ID範囲、本文と読みの違いは [kahara/messages.md](../kahara/messages.md)。oahu のID範囲とタグの確認状況は [oahu/analysis.md](../oahu/analysis.md)。kaharaで解析済みの検索規則を、未確認のoahuへそのまま適用しない。

# 共通仕様

対象は kahara（RPG2 1.1.0）と oahu（RPG3 Base v0 + Update v4096）。両作で確認された形式だけをまとめる。lanai（RPG FREE! Update v17408）はアーカイブのヘッダーと GS テーブル・メッセージの形式が違う（[formats.md](formats.md#lanai-rpg-free-の違い)）。

| 調べたいこと | 文書 |
|---|---|
| GSアーカイブ・GSテーブル・GMSGの形式と作品間の差 | [formats.md](formats.md) |
| 資料の再編、訂正根拠、残った疑義 | [reorganization.md](reorganization.md) |
| CIAの識別、展開、更新データの適用 | [../roms/README.md](../roms/README.md) |

共通のコンテナに入っていても、行サイズ、フィールド、ID、ハッシュ、アドレスは作品ごとに異なる。ゲーム仕様は [kahara](../kahara/README.md)、[oahu](../oahu/README.md)、[lanai](../lanai/README.md) へ進む。

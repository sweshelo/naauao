# 電波人間のRPG2 (kahara): ショップ

対象: 日本版 Title ID `00040000000A7900`、TitleVersion 1040 (1.1.0)。アドレスは展開済み code.bin の仮想アドレス (base `0x100000`)。[解析案内](analysis.md) / [ROM の識別・展開](../roms/kahara.md)。

## ShopItem テーブル (hash 0x67297400, 1D37838B と 49A43B63 に同一内容で格納)
443 行 × 8 バイト: `s32 店ID (-1 = 前行の続き), u32 アイテムID`。
店ID >= 0 の行 (アイテム欄は 0) が各ショップの先頭で、続く -1 行が品揃え。店ID は 0〜17。
ショップ UI: `FUN_001d4bfc` が `FUN_002ebf3c(list, 0x67297400)` でテーブル取得。
※ vendor.bin はショップとは無関係。

## Shop テーブル (hash 0xD5CEF800, 49A43B63 内, 18 行 × 0x38)
店 ID ごとの設定。+0x0C〜+0x30 が店員メッセージ ID (いらっしゃい/どうする/数入力/…)、+0x34 の値 が
**商品説明のバリアント**: 0 → item+0x14、1 → item+0x18、2 → item+0x1C。
- 店員メッセージセット: 0xBE/0xBF〜 (ちていじん Ď)、0xC8〜 (Ď)、0xD1〜 (ď です調)、0xDA〜 (č)、**0xE3〜 (妖精・自然な口調)**
- **店 17 = 妖精の里** (0xE3 系 + バリアント 2、品揃えに ようせいのはね)

品揃え一覧は [reference/shops.md](reference/shops.md)、アイテム行の説明文欄は [items.md](items.md)。

Shop は 0x38 バイトの行なので、旧記述の「最終バイト (+0x34)」という表現は不正確。+0x34 のバリアント値とフィールド幅は分けて扱い、幅・+0x35〜0x37 の意味は未確認とする。

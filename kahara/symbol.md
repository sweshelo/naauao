# マップのシンボルの敵の動き (追跡)

> 対象: 電波人間のRPG2 (`kahara`) v1.1.0。分類: ゲーム既存仕様。
> 根拠: `code.bin` の逆アセンブル (本文の関数) と、RomFS `2713402F` の `monsterDesign.bin` (165 行) の実データ。動作はコードからの解釈で、実機・エミュレーターでの観察はまだしていない。
> アドレスは実行時アドレス (`code.bin` の位置 = アドレス − `0x100000`)。RPG3・FREE! には適用しない。

マップに出たシンボルの敵が、プレイヤーに気づく前にどう動き、気づいたあと何をするか (追いかける・突進する・逃げる…)。
どの敵がどこに出るかは [エンカウント](encounters.md)、モデルとモーションは [モンスターのアニメーション](monster-motion.md)。

## 1. 流れ

1. シンボルを出す (`FUN_0021d190` → `FUN_002d6628`)。見た目と動きは、群れの先頭の候補 (固定の戦闘なら monsterFixGroup の最初のモンスター) の MonsterParameter +0x4C が指す **MonsterDesign の行** (`FUN_002d6998`)。
2. シンボルのオブジェクト (0x88 バイト、`FUN_001c4d88`) の +0x18 に動きの状態を作る。`FUN_001ee5e0(状態, デザインの行, フィールド, 位置)` が MonsterDesign +0x08 / +0x0C を読む (§2)。
3. 毎フレーム `FUN_001eee7c` が状態 (+1) を進める (§3)。気づく判定は `FUN_001eeaf0` (§4)。

フィールド +0xA8D0 が 2 のマップ (ワールドマップ。シンボルを 300 × 300 マスの周りに出す処理 `FUN_002d62ec` と同じ条件) では、状態 +0x50 の bit2 が立ち、見える距離が 2 倍・速さが別の値になる。

## 2. MonsterDesign の欄 (+0x08 / +0x0C)

| 位置 | ビット | 状態の欄 | 内容 |
|---|---|---|---|
| +0x08 | 0-2 | +4 | **動き方** (§2.1)。+0 (気づき方) も決める: 0〜3 → 1、4 → 2、5 → 4、6 → 8 |
| +0x08 | 3-4 | +3 | **出方・歩き方** (§2.2) |
| +0x08 | 5-11 | +0x38 | 待つ時間の最小 (× 0.1 秒) |
| +0x08 | 12-18 | +0x3C | 待つ時間の最大 (× 0.1 秒)。毎回 最小〜最大 の乱数 (`FUN_002f2068`) |
| +0x08 | 19-25 | +0x40 | 歩く時間 (× 0.1 秒) |
| +0x08 | 26-31 | | 全行 16。読み手は未確認 |
| +0x0C | 0-6 | +0x44 | 追う時間 (× 0.1 秒) |
| +0x0C | 7-16 | +0x48 | 見える距離 (ワールドの単位、ダンジョンの 1 マス = 500)。ワールドマップでは × 2 |
| +0x0C | 17 | +0x50 bit0 | **飛ぶ**。マップの mapData の行 [1] が 5 のときだけ立つ (`FUN_0043df38`) |
| +0x0C | 18-31 | | 全行 0x1A0。読み手は未確認 |

- +0x4C (視野の半角) は定数 π/2。前方 ±90° のプレイヤーに気づく。
- 実データの分布 (165 行): 動き方 0 = 67、1 = 49、2 = 17、3 = 14、4 = 5、6 = 13 (5 と 7 は使われない)。出方 0 = 107、1 = 41、2 = 17。飛ぶ = 39 行。待つ時間は 0.5〜5.0 秒、歩く時間は 6.0 / 8.0 秒、追う時間は全行 5.0 秒、見える距離は 185〜780 (多くは 600)。

### 2.1 動き方 (+0x08 bit0-2)

| 値 | 気づき方 (+0) | 気づいたあと | 例 (デザインの行) |
|---|---|---|---|
| 0 | 1: 距離 + 視野 + 壁 | 追いかける。速さ「速い」 | 3、23 |
| 1 | 1 | 追いかける。速さ「ふつう」 | 1、6 |
| 2 | 1 | 追いかける。速さ「遅い」 | 0、11 |
| 3 | 1 | **突進**: 気づいたときのプレイヤーの方向へ、向きを変えずに 4 秒走る (速さ 750)。気づいてからの間が 0.1 秒長い | 4、7 |
| 4 | 2: 前 600・後ろ 400 (見える距離の欄を使わない) | **逃げる**: プレイヤーと反対へ 1.7 秒走り (速さ 250)、状態 7 になる (消えると推定) | 64〜67、80 |
| 5 | 4: 気づかない | (動かない) | なし |
| 6 | 8: 距離 + 視野。**壁を確かめない** | 追いかける。速さは既定値 (520) | 27〜29、135〜137 |
| 7 | 0: 気づかない | (動かない) | なし |

追いかける (0〜2・6) は、毎フレーム向きをプレイヤーへ直す (`FUN_001eee7c` 状態 4)。追う時間が切れるか、見える距離 + 100 (800 未満なら 800) より離れると待つ状態に戻る。突進は時間切れで待つ状態に戻る。

### 2.2 出方・歩き方 (+0x08 bit3-4)

| 値 | 内容 |
|---|---|
| 0 | ふつう。その場に現れ (状態 0)、待つ (1) と歩く (3、速さ 150) をくり返す |
| 1 | 出るとき上から落ちてきて着地で弾む (状態 0。高さ 300、ワールドマップでは 200) |
| 2 | 待ったあと、半分の確率で歩く代わりに跳ねる (状態 5。距離 50〜200)。出るときに `FUN_001a1370` も呼ぶ |
| 3 | 0 と同じ |

## 3. 状態 (+1、`FUN_001eee7c`)

| 値 | 内容 |
|---|---|
| 0 | 出現中 |
| 1 | 待つ (+0x20 = 待つ時間)。時間が来たら 3 (歩く) か 5 (跳ねる) |
| 2 | 気づいた (`FUN_001eeaf0`)。ダンジョンでは 0.2〜0.4 秒、ワールドマップでは距離で 0.1〜0.2 秒の間を置いて、`FUN_001ed820` で 4 へ |
| 3 | 歩く (+0x20 = 歩く時間、+0x2C = 速さ 150)。壁で向きを変える |
| 4 | 追う・突進・逃げる (+0x20 = 時間、+0x2C = 速さ。アニメ 0x44) |
| 5 | 跳ねる |
| 6〜8 | 消える・戦闘への移行など (未確認) |

## 4. 気づく判定 (`FUN_001eeaf0`)

- 状態 1 (待つ) と 3 (歩く) のときに呼ばれる。
- 気づき方 1 / 8: 距離² ≤ 見える距離² で、前方との角度 ≤ +0x4C (π/2) のとき。気づき方 1 だけ、間の壁を raycast (`FUN_003321f4`) で確かめる。
- 気づき方 2 (逃げる): 前方 ±90° なら距離 600、後ろなら 400 まで。
- 気づき方 4 と 0: 気づかない。
- 気づいたら `FUN_00132ecc(…, 0x66, 0)` (効果音と推定) を呼び、状態 2 にする。

## 5. 速さ・時間 (コードの定数)

速さはデザインの行になく、`FUN_001ed820` (状態 2 → 4) と `FUN_001ee088` (状態 1 → 3) が自分のリテラルプールから読む。どのリテラルも 1 命令だけが読む (pc 相対の `ldr` / `vldr` は ±4 KB しか届かないので、0x1E0000〜0x200000 の全命令を調べて確認)。速さの単位はワールドの単位 / 秒。

| アドレス | 値 | 使い道 | 読む命令 |
|---|---|---|---|
| `0x1EDA10` | 680 | 動き方 0 (ワールドマップ) | `0x1ED894` |
| `0x1EDA14` | 620 | 動き方 0 (ダンジョン) | `0x1ED898` |
| `0x1EDA18` | 600 | 動き方 1 (ワールドマップ) | `0x1ED8A8` |
| `0x1EDA0C` | 520 | 動き方 1 (ダンジョン)、5〜7 (どこでも) | `0x1ED860` |
| `0x1EDA1C` | 420 | 動き方 2 (ワールドマップ) | `0x1ED8C0` |
| `0x1EDA20` | 400 | 動き方 2 (ダンジョン) | `0x1ED8C4` |
| `0x1EDA24` | 4.0 | 突進の時間 (秒) | `0x1ED8CC` |
| `0x1EDA28` | 750 | 突進の速さ | `0x1ED8D0` |
| `0x1EDA2C` | 1.7 | 逃げる時間 (秒) | `0x1ED934` |
| `0x1EDA30` | 250 | 逃げる速さ | `0x1ED938` |
| `0x1EE238` | 150 | 歩く速さ (気づく前) | `0x1EE0B0` |

- 時間の欄 (§2) に掛ける 0.1 は `0x1EE814`、ワールドマップの見える距離の 2 倍は `0x1EE834` (`FUN_001ee5e0`)。
- `FUN_001ed820` は `ldrb r0, [r4, #4]` (動き方) で 5 未満なら表 `0x1ED878` に飛び、5 以上は既定の 520 のまま。

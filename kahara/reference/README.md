# Kahara の個別データ

対象: RPG2 1.1.0。各表は既存の生成済みデータを保全したもの。生成器は本リポジトリに含まれず、現在の所在が確認できていないものもある。RPG3へは流用しない。

| 検索キー | 表 |
|---|---|
| actionData行番号・名前 | [actions.md](actions.md) |
| conditionData ID・名前 | [conditions.md](conditions.md) |
| MonsterParameter行・種族・能力・AI | [monsters.md](monsters.md) |
| アイテムID・名前・分類 | [items.md](items.md) |
| 装備ID・部位・効果 | [equipment.md](equipment.md) |
| 店ID・品揃え | [shops.md](shops.md) |
| マップ・イベント行・中身 | [treasures.md](treasures.md) |
| ダンジョンID・名前・コード | [dungeons.md](dungeons.md) |
| マップコード・ハッシュ | [maps.md](maps.md) |
| ダンジョン・マップ・EventObject行 | [events.md](events.md) |
| 種類0x24のクラス・処理・完了行 | [scripts.md](scripts.md) |

`rg -n` でIDや名前を検索し、見つかった行と関連見出しだけを読む。仕様は [作品索引](../README.md) から参照する。

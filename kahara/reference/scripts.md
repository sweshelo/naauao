# スクリプト (種類 0x24) 一覧

> 対象: **電波人間のRPG2 (`kahara`)**。v1.1.0 の解析文書に付属した既存の抽出一覧。生成元 ROM のハッシュ・生成日時は旧記録に未記載で、再編時の再抽出は行っていない。RPG3 (`oahu`) の一覧ではない。

旧作業環境の `tools/gen_scripts.py` で生成 (本リポジトリに未収録、現在の所在は未確認)。種類 0x24 の EventObject の行ごとに、ゲームが作る動作のクラスと、そのクラスが使うメッセージ・完了させる行を並べる。求め方は [event-list.md](../event-list.md) §3。
振り分け = 呼ばれる「動作の生成」関数 (参照している区画から決まる。参照がない行は全部を試して結果が出たもの)。クラス = 作られるオブジェクトの vtable。処理 = そのクラスだけが持つ vtable の関数。
完了 = `FUN_0031aa2c(定数)` で完了させる行。メッセージ = 処理から呼ばれる関数 (呼び出し元が 6 か所以下のもの) の literal pool にある MessageField の ID。先頭 3 つの本文を出す。

v1.1.0: 0x24 の行 393。マップから参照される 320 行のうち 317 行、参照されない 73 行のうち 22 行でクラスを特定。クラス 311 (うちメッセージを持つもの 175)。コードに直接書かれたメッセージ 1024 ID のうち 687 ID をどれかのクラスから辿れる。

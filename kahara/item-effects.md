# アイテムの効果

> 対象: **電波人間のRPG2 (`kahara`) v1.1.0**。根拠は本文のコードアドレス・ROM テーブルと旧解析記録。RPG3 (`oahu`) への適用は未確認。MOD 拡張はバニラ仕様と区別して読む。

アイテム (itemData、[items.md](items.md) の「itemData.bin」) が及ぼす効果の置き場所と計算。
ツールの表示・編集機能は [Panana 連携メモ](../integrations/panana/kahara-battle.md) を参照。

## 0. 要点

| 大分類 (+0x2C の下位 4 ビット) | 効果の欄 | 仕組み |
|---|---|---|
| 1 道具 | +0x24 = アクション (actionData) の行 | 使うとそのアクションを実行する (`FUN_002f6794`)。§1 |
| 3 装備 | +0x2D / +0x2E = 状態 (conditionData の ID)、+0x24 / +0x26 = その値 (s16) | 装備している間、電波人間の状態の欄に値を入れる。§2 |
| 4 つりざお / 5 エサ | +0x2D = 段階・種類の番号 (推定) | §3 |
| 2 ゴールド | なし | |

+0x24 は大分類ごとに意味が違う (道具は u32 のアクション行、装備は s16 × 2、たね・花は下記)。

## 1. 道具 (大分類 1)

- +0x24 (u32) = actionData の行。`FUN_002f6794` (アイテム → アクション) が大分類 1 のときだけ `ldrsh [+0x24]` を返す。
- 効果の中身 (回復量、状態の回復、復活、範囲) はアクションの欄 ([battle.md](battle.md) §8)。
- 使ったときに減るのはアクションの +0x14 のアイテム ([items.md](items.md) の「使ったときに減るアイテム」)。
- 使える場面はアイテムのフラグ (+0x08 bit2〜4) とアクションの w0 bit29〜31 の両方で決まる ([items.md](items.md) の「電波人間ハウスで使えるアイテム」)。
- 小分類 0xD (ペイントざい) も大分類 1 で、+0x24 はアクション #213〜#225 (ペイントおとしは #225)、+0x2D は色の番号。

## 2. 装備 (大分類 3)

### 2.1 欄

| 位置 | 型 | 内容 |
|---|---|---|
| +0x2C | u8 | 0xN3: N = 装備の欄 (0 首 / 1 腕 / 2 足 / 3 背中 / 4 服) |
| +0x2D | u8 | 効果 1 の状態 (conditionData の ID、0 = なし) |
| +0x24 | s16 | 効果 1 の値 |
| +0x2E | u8 | 効果 2 の状態 (0 = なし) |
| +0x26 | s16 | 効果 2 の値 |

読み出しは `FUN_0030a3d0(?, アイテム ID, 番号, &値)`: 番号 0 → +0x2D と +0x24、番号 1 → +0x2E と +0x26 を返す。
ほかに +0x2D だけを返す `FUN_001cd04c`、+0x2E だけを返す `FUN_00290b48` がある (呼び出し元は未確認)。

### 2.2 ユニットへの反映 (`FUN_0030a420(unit)`)

```
for 欄 in 0..4:                      # 首・腕・足・背中・服
    全状態 (94 件) の 欄 番目の値を初期値にする      (FUN_0025b7bc)
    item = unit +0x32 + 欄 × 2 (u16、装備しているアイテム)
    (大分類, 小分類) = FUN_0030b278(item)
    if 大分類 != 3 or 小分類 != 欄: 次へ            # 欄の違う装備は効かない
    for k in 0, 1:
        状態, 値 = FUN_0030a3d0(item, k)
        if 状態: unit +0xB0 + 状態 × 20 の 欄 番目の値 = 値    (FUN_0025b90c)
```

呼び出し元: `FUN_00309f68` (セーブの記録から戦闘・フィールドのユニットを作る)、`FUN_00199380` (装備の画面で、候補を着けたときの能力を比べる)、`FUN_00199a1c`、`FUN_002d82e0`。

### 2.3 状態の値の合わせ方 (`FUN_0030aff4`)

ユニットの状態 (+0xB0 + ID × 20、20 バイト) の欄:

| 位置 | 内容 |
|---|---|
| +0x00 | s16 元の値 |
| +0x02 / +0x04 | s16 最大 / 最小 (conditionData +0x06 / +0x04) |
| +0x06〜+0x10 | s16 × 6 = 値の出どころ。0〜4 が装備の欄 (首・腕・足・背中・服)、5 は装備以外 (未確認) |
| +0x12 | s8 残りターン |
| +0x13 | u8 合わせ方 = conditionData +0x32 の下位 4 ビット (`FUN_00435268` → `FUN_0025b838`) |

出どころの初期値は、合わせ方 3 なら 1、4 なら 100、ほかは 0。値は次のように計算し、最後に最小〜最大に収める。

| 合わせ方 | 計算 | 例 (conditionData) |
|---|---|---|
| 0 | 元の値のまま (装備は効かない) | (使われていない) |
| 1 / 2 | 元の値 + 出どころの合計 | 1: 能力 (40〜45)、能力のアップ・ダウン (31〜39)、属性のたいせい (51〜59)、追加打撃 (19)。2: HP / AP 自動回復 (27 / 28)、にげる (83) |
| 3 | 元の値 × 出どころの積 | (使われていない) |
| 4 | 元の値 × 出どころ 1 / 100 × 出どころ 2 / 100 … (1 つずつ 100 で割る) | 使用AP軽減 (30)、防御パラメータ倍 (46)、ダメージ倍率 (49)、経験値 / ゴールド増加 (78 / 79)、ドロップ率アップ (80〜82) |
| 5 | 元の値が最大と同じならそのまま、でなければ 1 と同じ | 状態異常・能力ダウン・突然死のたいせい (60〜77) |
| 6 | 0 でない出どころで上書き (後ろが勝つ。順は 首 → 足 → 背中 → 服 → 腕 → 5) | 状態異常 (1〜13)、興奮 (14)、必中 (15)、反射 (23)、浮遊 (24)、ゴーストバスター (25)、貫通 (26)、加速 (29)、打撃属性付加 (47)、打撃状態異常付加 (48)、誘惑 (87)、床ダメージなし (92) など |
| 7 | 元の値と出どころのうち最大 | クリティカル率増加 (16)、固定ダメージ (18)、行動回数 (86) |

したがって:
- **たいせい**は + で強くなる (モンスターの耐性と同じ向き。状態異常は +9 で 0%、[battle.md](battle.md) §6)。同じたいせいの装備を重ねると足し算。
- **経験値・ゴールド・ドロップ率**の補正は % で、重ねると掛け算 (120% と 150% で 180%)。ドロップの段階値は別途分母表を引き、状態0x50〜0x52の補正から確率分母を計算する。今回ゲームコードを局所確認した式・丸めは [battle.md §2.1](battle.md#21-ドロップ率の段階と補正今回の局所確認) を参照。Pananaの表示式とゲーム内部の整数変換は区別する。
- **打撃属性付加 (47)** の値は属性の番号 (1 火 / 2 氷 / 3 風 / 4 土 / 5 電気 / 6 水 / 7 光 / 8 闇)、**打撃状態異常付加 (48)** の値はアクションの行 (例: しにがみのカマ #247)。どちらも「上書き」なので、複数の装備にあると腕の装備が勝つ。
- 装備の値は conditionData の範囲に収まる (例: かいひりつ −100〜50、使用AP軽減 50〜100)。

### 2.4 実データ

[reference/equipment.md](reference/equipment.md) に全 284 件の装備の効果を出した (panana のアイテム図鑑と同じ表記)。
装備で使われている状態は 56 種類。数が多いのは ぼうぎょ (103 件)、こうげきりょく (31)、すばやさ (26)、打撃属性付加 (25)、かいひりつ (17)。
「めざましのスカーフ」= ねむりたいせい +1、「めざましのリボン」= +2 のように、同じ名前の系列は欄と値が違う。
誘惑 (87)・興奮 (14)・ターゲット (88) を付ける装備もある (バレエシューズ、まと、かわいいあのこ など)。着けた電波人間がその状態になると見られるが、戦闘での働きは確かめていない。

## 3. そのほかの分類 (データからの推定)

コードでは確かめていない。値の並びからの推定。

| 分類 | 欄 | 推定 |
|---|---|---|
| たね (0x21) | +0x26 = 通し番号 (1〜0x3D)、+0x2D = 花の色、+0x2E = 種類 (7 花 / 8 能力のたね / 9 くだもの) | 同じ通し番号の花・フルーツ (0x71 / 0x81 / 0x91) の +0x26 と一致する。育つ先 |
| 花 (0x71) | +0x26 = たねの通し番号、+0x2D = 色 | |
| 能力のフルーツ (0x81) | +0x24 = アクション (#208〜#212)、+0x26 = たねの通し番号 | 大分類 1 なので道具として使える |
| ペイントざい (0xD1) | +0x24 = アクション、+0x2D = 色 | §1 |
| つりざお (4) | +0x2D = 段階 0〜4 (つりざお → たくみのさお) | |
| エサ (5) | +0x2D = エサの種類 0〜12 | 釣れる魚の組 |

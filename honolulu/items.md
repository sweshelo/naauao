# 電波人間のRPG (honolulu): アイテム

対象: 日本版 Base Title ID `0004000000077E00`、TitleVersion 1024 (1.0.0)。[解析の入口](analysis.md) / [店](shops.md)。

## 1. アイテムに 3D モデルがない (データ)

- itemData にモデルの欄がない (行は 0x1C バイトで、アーカイブ・エントリのハッシュを置ける欄がない)。RPG2 は itemData +0x20 がモデル、RPG3 は +0x28、RPG FREE! は ItemDataCore +0x18 / +0x1C ([common/models.md](../common/models.md#6-アイテムのモデル))。
- 道具・装備のモデルを入れたアーカイブもない。RPG2 の `1D37838B` は本作ではアンテナのアイコン (`antenna001〜125.bclim` を入れた darc) と MessageEvent で、モデルは入っていない。
- ふく (分類 4) だけが見た目を持ち、clothData 経由でテクスチャを引く (§3)。
- したがって、アイテムの一覧・詳細に写真や 3D ビューは作れない。アイコンを出すなら、分類・☆ などから作った記号か、ふくのテクスチャだけになる。

## 2. itemData (master エントリ 51、298 × 0x1C)

298 行のうち中身のある行は 235 行 (+0x18 = 1)。残りは 0 埋めの空き行。

| 位置 | 型 | 内容 | 確度 |
|---|---|---|---|
| +0x00 | u32 | 名前のメッセージ ID (661〜) | データ |
| +0x04 | u32 | 説明のメッセージ ID (716〜) | データ |
| +0x08 | u32 | 店員の説明のメッセージ ID (150〜388)。0 = なし | データ |
| +0x0C | u32 | 買値 (G) | データ |
| +0x10 | u32 | 売値 (G) | データ |
| +0x14 | u8 | 種類のビット。0x01 装備・ふく、0x02 ？、0x10 だいじなもの系 (テレポーター・おそなえもの・「〜のもと」・あかし)、0x08 (0x19 / 0x1B = 道具)、0x20 (0x33 = フルーツ) | 推定 |
| +0x15 | u8 | いつも 0x34 | — |
| +0x18 | u8 | 1 = 中身のある行、0 = 空き | データ |
| +0x19 | u8 | 分類 3 では equipData の行、分類 4 では clothData の行 (§3)。ほかの分類では 0 | データ |
| +0x1A | u8 | 分類: 1 = 道具・だいじなもの (51 行)、3 = 装備 (83 行)、4 = ふく (101 行)、5 = あみ (3 行)、6 = ？ (14 行、名前が「ダミー」)、0 = 空き | データ |
| +0x1B | u8 | いつも 0xD0 (詰め物) | — |

- +0x16 はすべて 0。☆ (レア度) や所持数の上限に当たる欄は見つかっていない。RPG2 の itemData は 0x30 バイトで欄がもっと多いので、流用しない。
- 使用効果 (アクション) の欄もない。master に actionData の表がなく、道具の効果は店員の説明 (+0x08) の文からしか読めない。効果の実体がどこにあるかは未解析。

## 3. 装備とふく

### 3.1 equipData (master エントリ 53、198 × 0x18)

| 位置 | 型 | 内容 | 確度 |
|---|---|---|---|
| +0x08 | u32 | itemData の行 (itemData +0x19 から引いた行と相互に一致) | データ |
| +0x0C | u32 | 効果の値 (例: いのちのピアス 0x1400、イヤリング 0x2300 と増える) | 推定 |
| +0x00 / +0x04 / +0x10 | u32 | 0 の行が多い。意味は未解析 | — |

### 3.2 clothData (master エントリ 52、102 × 8)

| 位置 | 型 | 内容 | 確度 |
|---|---|---|---|
| +0x00 | u32 | ふくのテクスチャ (`B50A5EA9` のエントリのハッシュ。例: 行 1 = `CE02F800`) | データ |
| +0x04 | u8 | 行ごとに増える番号 (行 1 = 0x56)。模様の番号と推定 | 推定 |

- ふくのアイテム (分類 4) は itemData +0x19 → clothData の行 → `B50A5EA9` の CGFX というたどり方。`B50A5EA9` は CGFX 123 個。

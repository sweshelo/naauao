# 他作品の BGM を RPG2 へ移植する (Panana)

> 対象: 電波人間のRPG2 (`kahara`) v1.1.0 への MOD。移植元は初代・RPG3・RPG FREE! のストリームの曲。分類: Panana の拡張仕様 (ゲーム上の動作は未確認)。
> 形式の実測は [kahara/encounters.md](../../kahara/encounters.md) の「4.1 サウンドアーカイブとストリームの並び」。実装は Panana の `src/sound/write.ts`・`src/port/sounds.ts`・`src/port/bgm.ts`。

## 1. 書き出すもの

- `romfs/sound/stream/<名前>.bcstm`: 移植元のストリームを CSTM 2.1 に直したもの。2.2 (RPG3・FREE!) は stream info の後ろの 12 B (region の欄) を track の表 (1 本) に置き換え、channel の表の直後に track (音量 0x7F・パン 0x40・全チャンネルの番号) を挟む。2.0 (初代) は 2.1 と並びが同じなのでそのまま。
- `romfs/sound/sound.bcsar`: 音 430 以降に、移植した曲のストリームの音を足したもの。要素は RPG2 の音 0 (`BGM_TITLE`) の写しで、ファイル・音量 (移植元の音の値)・名前・確保するチャンネル数だけを変える。ファイルの表には外部ファイルの要素 (`stream/<名前>.bcstm`) を足す。STRG は文字列表の末尾に名前を足し、名前の検索木は変えない。
- 名前は `BGM_<作品>_<元の名前から BGM_ を除いたもの>` (例: RPG3 の `BGM_BATTLE_1` → `BGM_OAHU_BATTLE_1`)。作品は `HONOLULU` / `OAHU` / `LANAI`。既存の名前と重なれば `_2` などを付ける。

## 2. どの番号で鳴らすか

マップ (mapData [4] / [5])・ボス戦の BGM は soundData の行を 1 バイトで持ち、行 1〜255 はすべて RPG2 の音で埋まっている。そこで、移植した音は**既存の行の +0x00 (アイテム ID) を `0x01000000 | 音の番号` に付け替えて**鳴らす。

- 付け替えた行を使うほかの場所の曲も変わる。元の音は sound.bcsar に残るので、+0x00 を戻せば元に戻る。
- 別案: BGM を鳴らす関数 (`FUN_0030378c` ほか) を code.ips で拡張し、効果音の番号帯を BGM の追加枠として読み替える。code.bin の解析が要るため未着手。

# 他作品の BGM を RPG2 へ移植する (Panana)

> 対象: 電波人間のRPG2 (`kahara`) v1.1.0 への MOD。移植元は初代・RPG3・RPG FREE! のストリームの曲。分類: Panana の拡張仕様 (ゲーム上の動作は未確認)。
> 形式の実測は [kahara/encounters.md](../../kahara/encounters.md) の「4.1 サウンドアーカイブとストリームの並び」。実装は Panana の `src/sound/write.ts`・`src/port/sounds.ts`・`src/port/bgm.ts`・`src/game/bgmext.ts`。

## 1. 書き出すもの

- `romfs/sound/stream/<名前>.bcstm`: 移植元のストリームを CSTM 2.1 に直したもの。2.2 (RPG3・FREE!) は stream info の後ろの 12 B (region の欄) を track の表 (1 本) に置き換え、channel の表の直後に track (音量 0x7F・パン 0x40・+3 = 1・全チャンネルの番号。RPG2 の BGM_TITLE と同じ 20 B) を挟む。2.0 (初代) は 2.1 と並びが同じなのでそのまま。
- `romfs/sound/sound.bcsar`: 音 430 以降に、移植した曲のストリームの音を足したもの。要素は RPG2 の音 0 (`BGM_TITLE`) の写しで、ファイル・音量 (移植元の音の値)・名前・確保するチャンネル数だけを変える。ファイルの表には外部ファイルの要素 (`stream/<名前>.bcstm`) を足す。STRG は文字列表の末尾に名前を足し、名前の検索木は変えない。
- 名前は `BGM_<作品>_<元の名前から BGM_ を除いたもの>` (例: RPG3 の `BGM_BATTLE_1` → `BGM_OAHU_BATTLE_1`)。作品は `HONOLULU` / `OAHU` / `LANAI`。既存の名## 2. どの番号で鳴らすか (コードのパッチ「BGM の追加枠」)

マップ (mapData [4] / [5])・ボス戦の BGM は soundData の行を 1 バイトで持ち、行 1〜255 はすべて RPG2 の音で埋まっている。ただし BGM の欄が使うのは 0x80 未満 (行 1〜34 の BGM・35〜50 の ME) だけなので、**欄の値 0x80〜0xFF を soundData の行 418〜545 (足した行) と読み替える**パッチを code.ips に入れる。

- 移植した音ごとに soundData の行を 418 から足す (行 1 の写しで、+0x00 を `0x01000000 | 音の番号` にする)。欄の値 0x80 + k = 行 418 + k。最大 128 曲。ゲームは soundData の行数をヘッダーから読むので、行を足すだけで音を引ける (行 → アイテム ID の範囲の確認は行数で行う)。
- 読み替える場所 (v1.1.0、VA):

| アドレス | 関数 | 元の命令 | 役割 |
|---|---|---|---|
| 0x303798 | FUN_0030378c | `mov r5, r0` | BGM の行を鳴らす (いまの行を 0x56FC08 +4 に u16 で持つ) |
| 0x308BB0 | FUN_00308bac | `mov r8, #0` | BGM を変える (同じ行が鳴っていれば何もしない) |
| 0x2E6208・0x2E640C | (ワールドマップの BGM) | `bl FUN_00303b44` | その行が鳴っているか。値は FUN_00303994 の戻り値と、それを保存した +0x1AD4 |
| 0x402224 | (フィールドの BGM) | `bl FUN_00303b44` | 同じ。値は +0x6C に保存した mapData [4] |
| 0x317D34 | FUN_00317d04 | `cmp r5, #5` | 場面の BGM。戦闘 (場面 5) では行 27 / 28 / 29 / 32 が鳴っていれば鳴らしたままにする (0x317E04 へ) |

  最初の 2 つは入口で、次の 3 つは呼び出しの前に r0 の 0x80〜0xFF を 418〜545 に直す。FUN_00303b44 は効果音の行 (データから読む u16。0x400928・0x3ff14c など) でも呼ばれるので、入口では直さない。最後の 0x317D34 は、戦闘の場面で足した行 (0x1A2 以上) が鳴っていれば、ボス戦の BGM と同じく 0x317E04 へ進む。
- 欄の値はどの経路でも範囲を確かめずに FUN_0030378c / FUN_00308bac へ渡る: ボス戦は FUN_002fc790 (r1 → r6 → 0x2fc868)、mapData [5] は 0x1e50c0 → 0x1e50e8 と 0x3ffd1c → 0x3ffd44、mapData [4] は FUN_002f8bd0 → FUN_0028f184 (マップのハッシュで定数の曲に差し替えることはある) → FUN_00308bac・FUN_003089c8・+0x6C。
- ゲームの音はどれも変わらない。
